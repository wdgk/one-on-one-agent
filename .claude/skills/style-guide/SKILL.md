# Style Guide（整形ルール）

## 文体
- 断定を避け、条件・前提・不確実性を明示
- “〜と言える”より“〜を示唆する/〜の可能性が高い”を優先
- 1行が長い箇条書きは分割

## 表記統一例
- Engineer / エンジニア：文書内でどちらかに統一
- EM：初出で Engineering Manager（EM）と書く
- AI agent：AIエージェント に統一、必要なら括弧で英語併記

## 参照
- [S#] は文末に付ける（例：〜である。[S3]）
- 不足している場合は [citation needed] を付け、勝手に補完しない

## レイアウト
- TL;DRは必ず短く
- 表で整理できるものは表に
- セクション末に “Unknowns / Next steps” を置く
